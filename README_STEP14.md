# DealMate Step14

수정 내용

1. 로그인 이후 모든 화면의 앱 프레임을 로그인/회원가입 화면처럼 고정했습니다.
   - 브라우저 크기에 따라 화면 전체가 길어지지 않도록 390px x 760px 모바일 프레임 기준으로 고정
   - 둥근 모서리와 흰색 카드형 앱 프레임 유지

2. 하단 탭바가 내용을 가리는 문제를 수정했습니다.
   - 하단 메뉴를 absolute/fixed 방식에서 일반 흐름으로 변경
   - 스크롤을 내리면 하단 메뉴도 함께 아래로 이동하도록 수정
   - 내용이 하단 메뉴 뒤에 가려지지 않도록 수정

3. 공구 탭의 `공구 상세페이지` 버튼 동작을 수정했습니다.
   - 공구 탭에서 `공구 상세페이지`를 누르면 바로 정산/상세 UI가 보이도록 변경
   - 기존처럼 모집 중 화면이 먼저 뜨지 않도록 query parameter로 초기 탭 구분

4. 공구 상세페이지 내부 탭 동작을 정리했습니다.
   - `모집 중` 탭: 모집 현황 + 공구 참여하기
   - `공구 상세페이지` 탭: 공구 정보 + 호스트 정산 요청/참여자 정산 확인 UI

5. 정산 UI는 흰색 배경, 카드, 파란 버튼 스타일로 통일했습니다.

실행 방법

```powershell
cd C:\Users\User\Desktop\dealmate
.\build.bat
java -jar dealmate.jar
```

브라우저 접속

```text
http://localhost:8080/login
```
