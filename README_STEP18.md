# DealMate Step 18

수정 내용:

1. OCR 오류 시 직접 입력 금액 반영
   - 직접 입력 칸에 금액 입력
   - `금액 변경` 버튼 클릭
   - 총 결제 금액과 1인당 정산 금액이 화면 위 카드에 반영됨
   - 0 이하 또는 잘못된 금액이면 `정산 금액 계산에 실패했습니다.` 팝업 표시

2. 리뷰 작성 대상 선택 추가
   - 리뷰 작성 화면에서 리뷰 대상을 먼저 선택
   - 호스트 또는 참여자를 선택한 뒤 별점/리뷰 내용 입력
   - 리뷰 내용 누락 시 `내용을 채워주세요.` 팝업 표시

3. 동네 인증 화면 크기 통일
   - 기존 별도 full-height UI 제거
   - 로그인 이후 화면과 같은 390px 앱 프레임/둥근 모서리 구조로 변경
   - 브라우저 크기와 상관없이 화면 크기 유지

실행:

```powershell
cd C:\Users\User\Desktop\dealmate
.\build.bat
java -jar dealmate.jar
```

접속:

```text
http://localhost:8080/login
```
