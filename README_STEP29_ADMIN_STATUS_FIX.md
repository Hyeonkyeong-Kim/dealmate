# DEALMATE STEP29 ADMIN STATUS FIX

## 수정 내용

1. 관리자 제재 버튼 동작 오류 수정
   - 24시간 제한 버튼 정상 동작
   - 계정 정지 버튼 정상 동작
   - 해제하기 버튼 정상 동작

2. 계정 상태 표시 오류 수정
   - 리뷰확인 탭과 유저관리 탭에서 `정산 지연`, `참여중`, `리뷰 확인 필요` 같은 공구 상태가 계정 상태로 잘못 보이던 문제 수정
   - 계정 상태는 `정상`, `24시간 활동 제한`, `계정 정지`만 표시되도록 수정

3. 사용자 데이터 저장 방식 수정
   - 기존 users.txt에서 `|` 문자가 섞여 계정 상태가 깨지던 문제 수정
   - V2 저장 형식으로 변경하여 리뷰/공구 요약/계정 상태가 서로 섞이지 않도록 수정

4. 관리자 액션 안정화
   - 관리자 화면에서 조치 버튼 클릭 시 admin 권한으로 처리되도록 보강

## 실행 방법

```powershell
cd C:\Users\User\Desktop\dealmate
.\build.bat
java -jar dealmate.jar
```

## 관리자 계정

```text
admin / admin123
```

## 확인할 것

1. 유저관리에서 24시간 제한 버튼 클릭 시 계정 상태가 `24시간 활동 제한`으로 변경되는지 확인
2. 계정 정지 버튼 클릭 시 계정 상태가 `계정 정지`로 변경되는지 확인
3. 해제하기 버튼 클릭 시 계정 상태가 `정상`으로 변경되는지 확인
4. 리뷰확인 탭에서도 계정 상태가 동일하게 반영되는지 확인
5. 공구 상태인 `정산 지연`, `참여중`, `리뷰 확인 필요`이 계정 상태로 표시되지 않는지 확인
