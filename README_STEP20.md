# DealMate Step20

## 수정 내용

1. 공구 글 작성 화면
   - 최대 참여 인원은 호스트 포함 전체 인원으로 안내한다.
   - 총 예상 결제 금액을 입력한다.
   - 총 예상 금액, 최대 참여 인원, 1인당 예상 금액 미리보기를 표시한다.
   - 최대 참여 인원은 2명 이상이어야 한다. 호스트만 있는 공구는 공동구매가 아니므로 등록하지 않는다.

2. 공구 목록 화면
   - 총 예상 금액과 1인당 예상 금액을 같이 표시한다.
   - 최대 참여 인원이 호스트 포함이라는 안내를 표시한다.
   - 내가 만든 공구는 참여하기 대신 '내가 만든 공구입니다' 버튼으로 표시한다.

3. 공구 참여 검증
   - 현재 로그인 사용자가 방의 hostId와 같으면 참여 불가 처리한다.
   - 이미 참여한 공구이면 중복 참여 불가 처리한다.
   - 모집 인원이 가득 찼으면 참여 불가 처리한다.
   - 실패 메시지는 Analysis 문서의 '모집 인원이 마감되었거나 참가할 수 없습니다.'를 사용한다.

4. 공구 상세페이지 / 정산 화면
   - 정산 대상 공구 정보를 항상 상단에 표시한다.
   - 정산 대상 공구명, 호스트, 참여 인원, 총 예상 금액, 1인당 예상 금액을 표시한다.
   - 호스트 정산 요청과 참여자 정산 확인 화면에서 어떤 공구의 정산인지 헷갈리지 않도록 공구명을 표시한다.
