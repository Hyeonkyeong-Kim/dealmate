# DealMate STEP12

수정 내용

1. 화면 크기/스크롤 문제 수정
- 브라우저 전체가 길어져 보이지 않도록 body 스크롤을 막고, 앱 화면 내부에서만 스크롤되도록 수정했다.
- 하단 탭바는 모바일 화면 내부 하단에 고정되도록 수정했다.
- 스크롤바가 UI 옆에 튀어나오지 않도록 숨김 처리했다.

2. 정산 상세 페이지 UI 수정
- 다른 화면과 동일하게 흰색 배경, 카드, 파란색 버튼 중심으로 통일했다.
- 이전처럼 혼자 회색/하늘색 배경으로 튀지 않게 수정했다.
- 정산 상세 페이지 상단에 참여 중인 공구 카드를 표시한다.

3. 호스트/참여자 정산 UI 분리
- 호스트 정산 요청 탭
  - 총 결제 금액
  - 참여 인원
  - 1인당 정산 금액
  - 결제 영수증 업로드
  - OCR 오류 시 직접 입력
  - 정산 요청 보내기

- 참여자 정산 확인 탭
  - 호스트 업로드 영수증
  - 총 결제 금액
  - 참여 인원
  - 1인당 정산 금액
  - 송금 인증 이미지 업로드
  - 송금 인증하기
  - 리뷰 작성하기

4. 오류 검증
- 정산 금액 직접 입력값이 0 이하이면 "정산 금액 계산에 실패했습니다." 팝업을 표시한다.

실행 방법

```powershell
cd C:\Users\User\Desktop\dealmate
.\build.bat
java -jar dealmate.jar
```

```text

```
