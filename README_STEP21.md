# DealMate Step21

## 수정 내용

1. 공구 탭의 `모집 중`과 `공구 상세페이지` 역할 분리
   - 모집 중: 전체 모집 중인 공구 목록 표시
   - 공구 상세페이지: 현재 로그인 사용자가 호스트이거나 멤버로 참여한 공구만 정산 대상으로 표시

2. 공구 상세페이지에서 정산 대상 공구 선택 기능 추가
   - 좌우 화살표로 내가 관련된 공구를 이동하며 선택
   - 선택된 공구에 따라 공구명, 호스트, 참여 인원, 총 예상 금액, 1인당 예상 금액, 마감 상태가 변경됨

3. 역할별 정산 UI 분리
   - 내가 호스트인 공구: 호스트 정산 요청 UI 표시
   - 내가 멤버로 참여한 공구: 참여자 정산 확인 UI 표시

4. 공구 목록 카드 버튼 정리
   - 모집 중 탭의 카드: `상세 보기`는 모집 상세로 이동
   - 상단 `공구 상세페이지` 탭: 내가 관련된 공구 정산 대상 선택 화면으로 이동

## 실행

```powershell
cd C:\Users\User\Desktop\dealmate
.\build.bat
java -jar dealmate.jar
```

브라우저 접속:

```text
http://localhost:8080/login
```
