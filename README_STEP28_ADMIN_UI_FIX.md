# DealMate Step28 Admin UI Fix

## 기준
- 사용자 UI는 step22_fix2 기준에서 변경하지 않음
- 관리자 UI만 수정

## 수정 내용
1. 리뷰확인 화면의 저평점 사용자 현황 카드 개선
   - 카드를 누르면 제재 필요 사용자만 모아보기
   - 모아보기 중에는 카드 색이 더 진하게 표시되어 현재 필터 적용 상태를 알 수 있음
   - 모아보기 중 다시 카드를 누르면 전체 리뷰 목록으로 돌아감

2. 리뷰확인 사용자 카드 compact 처리
   - 공지 카드처럼 크게 보이지 않도록 카드 높이와 여백 축소
   - 평균 별점, 리뷰 수, 계정 상태, 대표 리뷰를 한눈에 확인 가능하게 정리

3. 유저관리 제재 상태 필터 UI 복구
   - 기존의 예쁜 버튼형 pill-tab 스타일로 복구
   - 전체 / 24시간 제한 / 계정 정지 버튼이 한 줄에 표시됨

4. 기존 기능 유지
   - 별점 정렬은 드롭다운 유지
   - 낮은 별점순 / 높은 별점순 가능
   - 24시간 제한 필터: [계정 정지] [해제하기]
   - 계정 정지 필터: [24시간 제한] [해제하기]
   - 전체 필터: [24시간 제한] [계정 정지]
