# DealMate Step22

## 사용자 UI 마무리: 특가글 사진 첨부 선택사항 추가

- 특가 정보글 작성 화면에 사진 첨부 선택 UI를 추가했다.
- 제목과 내용은 필수 입력값이며, 사진은 선택사항이다.
- 사진을 선택하면 `이미지 첨부됨`으로 표시된다.
- 실제 이미지 서버 저장은 시연용으로 단순화하고, 특가글 상세 화면에서 `[이미지 미리보기]` 영역을 표시한다.
- 사진을 첨부하지 않아도 게시글 등록이 가능하다.

## 검증

- 제목 누락: `내용을 채워주세요.`
- 내용 누락: `내용을 채워주세요.`
- 사진 미첨부: 오류 없음
