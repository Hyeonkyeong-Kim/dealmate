# DealMate Step15

## 수정 내용

1. 로그인/홈/글쓰기/공구/마이 등 화면 프레임 위치를 통일했습니다.
   - 브라우저 전체 화면이 스크롤되지 않도록 `body`를 고정했습니다.
   - 앱 프레임은 390px x 760px 크기로 가운데에 고정했습니다.

2. 하단 메뉴 위치를 통일했습니다.
   - 하단 메뉴는 모든 주요 화면에서 앱 프레임 맨 아래에 고정됩니다.
   - 화면 내용만 하단 메뉴 위쪽 영역에서 스크롤됩니다.
   - 하단 메뉴가 내용이나 입력칸을 가리지 않도록 내부 스크롤 영역을 분리했습니다.

3. 공구 상세페이지 탭 동작은 유지했습니다.
   - 공구 탭에서 공구 상세페이지를 누르면 바로 정산 UI가 표시됩니다.

4. 정산 금액 직접 입력 기능을 수정했습니다.
   - OCR 오류 시 직접 입력 칸에 총 결제 금액을 입력하면 총 결제 금액과 1인당 정산 금액이 즉시 변경됩니다.
   - 참여 인원은 시연용으로 4명 기준입니다.
   - 0 이하 입력 시 “정산 금액 계산에 실패했습니다.” 팝업을 표시합니다.

5. 결제 영수증 업로드는 시연 모드에서 실제 파일 선택을 막았습니다.
   - 클릭 시 시연 모드 안내 팝업을 표시합니다.

## 실행 방법

```powershell
cd C:\Users\User\Desktop\dealmate
.\build.bat
java -jar dealmate.jar
```

브라우저에서 접속합니다.

```text
http://localhost:8080/login
```
